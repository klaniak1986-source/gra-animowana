# Manifest zasobów graficznych

W projekcie przygotowano dotychczas następujące grupy materiałów:

- zdjęcie referencyjne Jarka,
- zaakceptowany portret Jarka w stylu gry,
- chód w lewo,
- chód w prawo,
- chód do kamery,
- chód od kamery,
- animację bezczynności,
- animację podnoszenia przedmiotu,
- zestaw póz i gestów dialogowych,
- zdjęcia referencyjne lokacji,
- tło pierwszej lokacji bez postaci,
- materiały referencyjne określające styl retro point-and-click.

Pliki graficzne powinny docelowo trafić do katalogów:

- `assets/source/`
- `assets/characters/jarek/`
- `assets/locations/`
- `assets/references/`
